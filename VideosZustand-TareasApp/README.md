# Aplicación de Tareas

## Pasos para ejecutar el programa

1- Instalar dependencias:
  npm install
2- Ejecutar el Programa:
  npm run dev


## Funcionalidades principales

    Listar tareas: muestra todas las tareas existentes.

    Agregar tarea: abre un modal para crear una nueva tarea.

    Editar tarea: permite modificar una tarea existente.

    Eliminar tarea: elimina una tarea con confirmación previa.
